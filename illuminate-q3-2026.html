FRESH OFF THE BUILD:
New Features & Capabilities
Q3 brought a major platform evolution. Here is everything now live:
Ask Me: Powered by MCP
Ask Me just got smarter. Built on MCP, it reads intent accurately, routes questions to the right AI agent, and reasons across multiple questions like an analyst, not a chatbot.
Unified Drill-Through Analytics
Go from the big picture to granular detail without losing your place. Unified Drill-Through Analytics takes you from summary views straight into underlying data with full context intact.
AI Assistant for Custom Chart Creation
Describe the visualization you need in plain language and the AI Assistant builds it, turning natural-language requests into the right chart type and format with no manual configuration.
Automated Join Creation in Schema Manager
Schema Manager now auto-detects likely table relationships using column names, data types, and key metadata, pre-populating joins in the Join Builder so you can review and refine, not build from scratch.
AI-Assisted Variable Creation with Natural Language
Describe the calculation you need in plain language, and Lumenore generates the SQL or LQL expression using your schema and data context, ready to review, refine, and save in the editor.

About Lumenore

Lumenore, a Netlink flagship product, is an AI-based business intelligence and analytics platform that uses secured GenAI to provide businesses with deep insights into their data. It makes complex data analysis accessible and actionable for users of all skill levels through features like dashboards, natural language, conversational/chat analytics, narrative-based explanations and action. The platform simplifies the data collection, data integration and analysis process by allowing users to interact with their data in no-code/low-code way.
